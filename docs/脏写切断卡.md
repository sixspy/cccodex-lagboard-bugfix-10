# 脏写切断卡

- 产品：源到达SLA（批采入口挂在时限台调度区）
- 缺陷：批量超时半批已落库；重试又写出双份到达
- 择定路径：乙
- 路径口径：批次幂等键条件插入，遇重复键拒绝第二次并保留首批正式行
- 封档状态：已封档
- 封档日期：2026-11-19
- 依据簿册：`docs/批量超时脏写重试切断簿册.md`
- 登录：沿用脏写侧会话（`Authorization: Bearer <token>`）
- 库：单机 SQLite，挂脏写卷 `data/app.db`

## 执行口径

1. 批采入口只挂在「时限台 · 调度区」，不新开脏写台。
2. 甲、乙写路径不得混用，本仓只实现乙路径。
3. 整批在单事务内写入后按批次幂等键提交；超时/异常整批回退，不留半批。
4. 同一批次键的第二次提交按重复键拒绝，保留首批正式行。
5. 两席同时重试同一批须先占脏写锁；后交只记「批量脏写争用」，不落数据。
6. 任何偏离本卡的写请求一律拦下，并记「脏写偏了」。
7. 补采席队列、到达卡片、源名录、水位牌与对账附页均须无双份。

## 禁止

- 禁止只改重试按钮字样充当切断。
- 禁止跳过脏写失败测直接改落库。
- 禁止当日改口本卡或簿册。
